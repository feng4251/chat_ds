# ICH Guidelines Index — Clinical Trial Design Reference

## Purpose

Lightweight index of ICH efficacy and multidisciplinary guidelines relevant to clinical trial design assistance. Workers reference this index during their Knowledge Gate phase to determine which ICH guidelines apply to a given trial phase, design type, and population.

## How Workers Use This Index

1. Worker B (PICO & Standards) — checks PICO elements against applicable ICH guidelines
2. Worker C (Termination Analysis) — checks whether terminated trials violated ICH design principles
3. Worker D (I/E Criteria) — ensures I/E criteria follow ICH E3/E7/E8/E11 population standards

## Quick Reference by Trial Phase

### Phase I Trials
- **Must reference**: E2A (SAE reporting), E6(R2) (GCP), E8 (general design), M3(R2) (nonclinical prerequisites)
- **Often relevant**: E14 (QTc assessment), E15/E16 (PGx if applicable), E4 (if dose-escalation/finding)

### Phase II Trials
- **Must reference**: E2A, E6(R2), E8, E9 (statistical principles)
- **Often relevant**: E4 (dose-response), E10 (comparator), E9(R1) (estimands)

### Phase III Trials
- **Must reference**: E2A, E3 (CSR), E6(R2), E8, E9, E9(R1), E10
- **Often relevant**: E5 (multi-regional), E7 (geriatric), E17 (MRCT), E19 (safety data optimization)

### Phase IV / Post-Marketing
- **Must reference**: E2C, E2D, E2E, E6(R2)
- **Often relevant**: E2F (DSUR if still in development program)

## Quick Reference by Design Type

### Superiority Trials
- **Key**: E9 (hypothesis testing), E10 (placebo vs active control)

### Non-Inferiority Trials
- **Key**: E9, E10 (NI margin derivation: M1 from historical data, M2 from clinical judgment)
- **FDA**: "Non-Inferiority Clinical Trials" Guidance 2016
- **EMA**: "Guideline on the choice of the non-inferiority margin" 2006

### Equivalence Trials
- **Key**: E9, E10 (two one-sided tests [TOST] procedure)

### Adaptive Trials
- **Key**: E8, E9, E20 (in development)
- **FDA**: "Adaptive Designs for Clinical Trials" Guidance 2019

### Multi-Regional Clinical Trials (MRCT)
- **Key**: E5 (ethnic factors), E17 (MRCT design)
- **NMPA**: China-specific MRCT requirements for NMPA registration

## Search Strategies for Workers

When a Worker's Knowledge Gate triggers an ICH search:

1. **WebSearch**: "ICH [E-code] guideline PDF" → retrieve latest version
2. **FDA**: FDA.gov guidance search for disease-specific guidance
3. **EMA**: ema.europa.eu → Scientific guidelines → [therapeutic area]
4. **ICH Official**: ich.org/page/efficacy-guidelines
