## Test Sentiment Analysis Skill

This skill provides sentiment analysis capabilities.

### Instructions

When asked to analyze sentiment:
1. Read the text carefully
2. Classify as positive, negative, or neutral
3. Return the classification with a confidence score

### Example

Input: "I love this product!"
Output: {"sentiment": "positive", "confidence": 0.95}
